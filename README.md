# About Me:
I'm a Data Science and AI/ML enthusiast currently building toward a top-tier internship, with a strong foundation in mathematics and a sharp focus on turning raw data into real systems.<br>

Right now I'm developing Structura — a Python-based data preparation framework that automates the hardest 80% of any ML workflow: intelligent missing-value imputation, multi-source data merging, and feature alignment. It's not a tutorial project. It's built to solve a problem I kept running into.<br>

My technical foundation is grounded in strong Linear Algebra, Calculus, and Probability — the kind of math that makes ML make sense rather than just work. I'm advancing through Python with an emphasis on clean, structured code, and I'm beginning DSA with a disciplined pattern-based approach through Leetcode.<br>

Next up: NumPy, Pandas, Matplotlib, and applied machine learning — building toward end-to-end ML pipelines that go from messy data to deployed models.<br>

I don't just study this. I build it.<br>
